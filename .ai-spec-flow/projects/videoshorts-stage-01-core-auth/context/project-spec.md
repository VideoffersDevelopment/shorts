## Jak używać tego kontekstu

Podczas faz Analysis, Architecture i Tasks, AI powinno przeczytać pełną specyfikację projektu aby:

1. **Zrozumieć całościową wizję** - jakie są wszystkie moduły i etapy projektu
2. **Unikać duplikacji** - nie tworzyć komponentów które będą w innych etapach
3. **Planować integracje** - jak obecny etap łączy się z przyszłymi
4. **Zachować spójność** - nazewnictwo, konwencje, struktura

## Kluczowe sekcje w project-spec.md

- **Executive Summary** - czym jest VideoShorts
- **Typy Użytkowników** - User, Company, Admin
- **Wymagania Funkcjonalne** - wszystkie moduły (F-AUTH, F-COMP, F-SHORT, etc.)
- **Wymagania Niefunkcjonalne** - performance, security, compliance
- **Model Danych** - high-level ERD
- **Integracje Zewnętrzne** - Mux, Stripe, Mapbox, etc.
- **Architektura Etapowania** - 8 etapów MVP
